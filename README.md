## Какие файлы нужны для занятий

Клонируйте или скачайте репозиторий целиком: блокнот использует соседние файлы.

| Путь | Где используется |
|---|---|
| `agents/travel.py` | Один агент поездок для обоих способов A2A (§ 10–12) |
| `servers/` | MCP-сервер (§ 5–7), оба A2A-сервера (§ 10–12), AG-UI/A2UI (§ 13–14), ACP (§ 15) |
| `data/course/` | Файлы, которые читает собственный MCP-сервер; данные упражнения на занятии |
| `compat/a2ui_tool.py` | Адаптер A2UI с исправлением ошибки `Event loop is closed` в закреплённой версии (§ 14) |
| `licenses/` | Лицензия MIT включённого адаптера A2UI |
| `tools/check_env.py` | Проверка Python, пакетов и QR-декодера перед запуском |
| `skills/qr-code/` | Самостоятельный QR-навык для дополнительного раздела (§ 18) |
| `lab.py` | Запуск и остановка процессов, клиенты протоколов и отображение результатов |
| `slides/` | Презентация PDF и исходник Slidev |

Структура QR-навыка:

```text
skills/
└── qr-code/
    ├── SKILL.md
    └── scripts/
        ├── qr_generate.py
        └── qr_read.py
```

Имя папки `qr-code` совпадает с `name` в YAML файла `SKILL.md`.
`references/` и `assets/` добавляются, когда у навыка есть справочники или шаблоны; пустые папки не нужны.
Deep Agents получает каталог явно через параметр `skills`; в примере рабочая папка отображается в виртуальную файловую систему.
Структура соответствует [Agent Skills](https://agentskills.io/specification) и [подключению навыков Deep Agents](https://docs.langchain.com/oss/python/deepagents/skills).

## Установка

Нужен [uv](https://docs.astral.sh/uv/getting-started/installation/).
В корне скачанного репозитория выполните:

```bash
uv sync
```

Команда установит Python 3.12 и зависимости из `uv.lock` для всех частей методички.
Создайте `.env` на основе `.env.example`: `cp .env.example .env` в macOS/Linux,
`Copy-Item .env.example .env` в PowerShell или `copy .env.example .env` в Windows cmd.
Впишите `GIGACHAT_CREDENTIALS` — ключ авторизации из [кабинета GigaChat API](https://developers.sber.ru/studio/workspaces/my-space/get/gigachat-api).
Модель и scope задаются там же. `.env` исключён из Git.

```bash
uv run tools/check_env.py
uv run jupyter lab protocols.ipynb
```

Выберите ядро Python окружения проекта. Проверка в первой ячейке показывает версию интерпретатора и наличие ключа без его значения.
Установка выполняется один раз. В Jupyter запускайте ячейки сверху вниз; при начале со второй части сначала выполните общую настройку из раздела 1.

## Skills: QR-коды на разных ОС

Основная часть занятия не требует нативного декодера. Для дополнительного QR-примера нужен ZBar:

| ОС | Дополнение к `uv sync` |
|---|---|
| Windows x64 | DLL ZBar входят в wheel `pyzbar==0.1.9`. При ошибке загрузки установите [Visual C++ Redistributable 2013](https://www.microsoft.com/en-us/download/details.aspx?id=40784) x64 для x64 Python |
| macOS | `brew install zbar` или `brew bundle --file Brewfile` |
| Debian/Ubuntu | `sudo apt-get install libzbar0` |

Проверка до запуска модели:

```bash
uv run tools/check_env.py --qr
```

Она создаёт QR и читает его обратно. Включённый `qr_read.py` на macOS настраивает поиск библиотек Homebrew для Python из uv.
Установка DLL описана в [документации pyzbar](https://github.com/NaturalHistoryMuseum/pyzbar#installation).
Проверка Windows-wheel подтверждает наличие DLL; фактическое выполнение на Windows/Linux следует проверить в своей среде.

## Серверы и повторный запуск

Ячейки сами запускают дочерние процессы и проверяют их готовность. Используются локальные порты:
8765 — MCP, 9100 — A2A SDK, 9300 — Agent Server, 9200/9201 — AG-UI/A2UI.
Если порт занят посторонним процессом, методичка сообщает об этом. Повторный запуск своего сервера останавливает его прежний экземпляр.
В конце разделов есть ячейки остановки; общая команда — `lab.stop_all()`.
Журналы и временные файлы находятся в `.runtime/` и исключены из Git.

Агент обращается к публичным серверам Туту и ВкусВилла. Дата поездки вычисляется относительно дня запуска.
Цены и результаты могут меняться. Выполняйте модельные примеры последовательно: API может ограничивать параллельные запросы.
Создание ссылки на корзину не оформляет заказ. Вход в личный кабинет и платёжные операции в примерах не выполняются.

## Два способа A2A

`servers/a2a_sdk.py` публикует `agents.travel.travel_graph` через a2a-sdk.
`servers/agent_server.py` передаёт ту же фабрику в LangGraph Agent Server.
Общий клиент показывает JSON-RPC, завершённую задачу и artifact. Он также используется координатором с MCP ВкусВилла.
Постоянная история, отмена и весь набор возможностей двух серверных реализаций не сравниваются.

В выбранных версиях строгий protobuf-клиент a2a-sdk отклоняет поле `kind` в ответах Agent Server;
учебный JSON-RPC-клиент читает необходимые поля обоих форматов.

## Домашнее задание

Условия находятся в [homework_mcp_knowledge_base.pdf](homework_mcp_knowledge_base.pdf).

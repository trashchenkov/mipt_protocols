# Model Context Protocol

MCP описывает обмен между приложением и сервером инструментов и контекста.
Сервер публикует tools, resources и prompts. Приложение выбирает, какой контекст передать модели.
Инструмент выполняется на сервере, его результат возвращается клиенту.
Для локального процесса используется stdio; для удалённого сервиса — HTTP.
Версию спецификации обозначают датой. Версия Python SDK имеет отдельную нумерацию.
